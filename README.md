# 🎵 Summer Beats Festival - Galeria & Top Melhores do Ano

Projeto web desenvolvido em HTML5 puro, focado na construção de páginas estruturadas com tabelas semânticas, galeria visual do evento, suporte a vídeos via `iframe` e reprodução de áudio nativa via `<audio>`.

---

## 🚀 Funcionalidades

* **Galeria de Imagens e Vídeos:** Apresentação das atrações do festival (Palco Principal, Camping Universitário, Food Trucks e Espaço Cultural).
* **Ranking Top 5 Músicas:** Tabela estruturada listando os maiores sucessos do ano.
* **Player de Áudio Nativo:** Execução de prévias musicais integradas com a tag `<audio>` do HTML5.
* **Comentários Educativos:** Código fonte documentado com a explicação de cada tag utilizada.

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição |
| :--- | :--- |
| **HTML5** | Estruturação de marcação semântica |
| **Tabelas HTML** | Organização e alinhamento do conteúdo visual |
| **Mídia Nativa** | Tags `<audio>` e `<iframe>` para multimídia |
